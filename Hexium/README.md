# Stone Brick Walls

Adds brick-pattern stone building pieces that use Valheim's original stone wall texture.

## Pieces

Found in the hammer's **Stonecutter** tab (requires a nearby Stonecutter). Sizes are Length x Height x Width.

| Piece | Size | Stone |
|---|---|---|
| Stone brick cube | 2x2x2 | 12 |
| Stone brick cube, alt | 2x2x2 | 12 |
| Stone brick wall | 4x2x1 | 12 |
| Stone brick wall | 4x2x2 | 24 |
| Stone brick wall | 8x2x1 | 24 |
| Stone brick wall | 8x4x1 | 48 |
| Stone brick wall | 8x4x2 | 96 |
| Stone brick floor, basket weave | 4x4 (1 thick) | 24 |
| Stone brick floor, framed | 4x4 (1 thick) | 24 |

Every piece is built from the vanilla 2x1 and 1x1 stone blocks (the 2m thick walls from 2x1 blocks only), so it looks like you placed those blocks by hand.

Walls have 2500 health. Cubes and floors have the vanilla 2x1 stone block's health. Damage resistances and sounds are the same as the vanilla 2x1 stone block. Costs and crafting station can be changed in the config file and are synced from the server.

## Install

Requires BepInExPack for Valheim. Put `StoneBrickWalls.dll` in `BepInEx/plugins`. Install on the server and all clients.

## Logs

Messages from this mod show in the BepInEx console and `LogOutput.log` as `[Stone_Brick_Walls]: message`.
