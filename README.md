# Stone Brick Walls

Adds brick-pattern stone building pieces that use Valheim's original stone wall texture.

## Pieces

Use the Hammer to build. Need a nearby **Stonecutter**. Sizes are Length x Height x Width.

| Piece | Size | Stone |
|---|---|---|
| Stone brick cube | 2x2x2 | 12 |
| Stone brick cube, alt | 2x2x2 | 12 |
| Stone brick wall | 4x2x1 | 12 |
| Stone brick wall | 4x2x2 | 24 |
| Stone brick wall | 8x2x1 | 24 |
| Stone brick wall | 8x2x2 | 48 |
| Stone brick floor | 2x2 (0.5 thick) | 3 |
| Stone brick floor | 4x4 (0.5 thick) | 12 |

Health, damage resistances and sounds are the same as the vanilla stone wall. Costs and crafting station can be changed in the config file and are synced from the server.

## Install

Requires BepInExPack for Valheim. Put `StoneBrickWalls.dll` in `BepInEx/plugins`. Install on the server and all clients.
